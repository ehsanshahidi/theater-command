# Theater Command

A browser real-time strategy game. Play it at https://ehsanshahidi.github.io/theater-command/.

## This repository is build output only

This repository contains only the compiled site that GitHub Pages serves. The source code lives in a separate private repository.

Every push to that repository's `main` branch builds the game and force-pushes the result here as a single commit, replacing the previous history. Anything committed here directly will be overwritten by the next deploy, so please don't open pull requests against this repository.
